# 🏡 Real Estate Sales & Performance Dashboard | Power BI

## 📌 Project Overview

An interactive Real Estate Analytics Dashboard developed using Microsoft Power BI to monitor sales performance, analyze customer behavior, and evaluate real estate agent productivity.

The dashboard provides a comprehensive view of business performance through KPIs, interactive filters, geographical visualization, and comparative analysis.

It consists of two main analytical pages:

1. Sales Performance
2. Agents, Customers & Sales Funnel

## 🖼️ Dashboard Preview

### 1. Sales Performance

This page provides an overview of real estate sales performance across branches, cities, property types, and zone classifications.

**Key Performance Indicators (KPIs):**
- Total Sales Revenue
- Total Transactions
- Average Sale Price
- Sales Year-to-Date (YTD)
- Sales Year-over-Year (YoY) Growth

**Visualizations:**
- Sales revenue by branch.
- Geographical visualization by city.
- Sales distribution by property type.
- Revenue comparison across zone classifications (Luxury, Mid-Range, and Economic).

**Interactive Filters:**
- Year
- Month
- Branch Name
- City
- Zone Class
- Property Type

### 2. Agents, Customers & Sales Funnel

This page focuses on sales funnel performance, customer segmentation, and agent productivity.

**Key Performance Indicators (KPIs):**
- Total Showings
- Showing-to-Sale Conversion Rate
- Showings per Transaction
- Active Agents
- Revenue per Agent

**Visualizations:**
- Showings with feedback by income level.
- Total sales revenue by the top 5 agents.
- Buying customers by income level.
- Revenue per agent by specialization.

**Interactive Filters:**
- Year
- Month
- Branch Name
- Income Level
- Region
- Specialization

## 🎯 Project Objectives

- Monitor overall real estate sales performance.
- Compare revenue across branches and property categories.
- Analyze sales distribution across different market segments.
- Evaluate agent productivity and revenue contribution.
- Understand customer segmentation by income level.
- Monitor the relationship between property showings and completed sales.
- Present business performance through interactive visualizations.
